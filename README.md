# ej2-mvc-scheduler-copy-and-paste-appointments

## Repository Description

This repository demonstrates how to implement copy, cut, and paste functionality for appointments in the Syncfusion EJ2 Scheduler component using an ASP.NET MVC application. Users can manage calendar events efficiently using standard keyboard shortcuts.

## Features

- **Copy/Cut/Paste Appointments**: Full clipboard support for appointments using Ctrl+C, Ctrl+X, and Ctrl+V
- **Keyboard Shortcuts**: Standard keyboard shortcuts for efficient event management
- **Event Management**: Automatic ID generation and property preservation during operations
- **Responsive Design**: Works seamlessly across different devices and screen sizes

## Technologies Used

- **Framework**: ASP.NET MVC 5
- **Components**: Syncfusion EJ2 Scheduler
- **Language**: C# with Razor Views and JavaScript
- **Styling**: Bootstrap 5

## Prerequisites

- Visual Studio 2019 or later
- .NET Framework 4.7.2 or higher
- Syncfusion EJ2 NuGet packages (included in packages.config)
- Basic knowledge of ASP.NET MVC

## Installation

1. Clone this repository to your local machine
2. Open the project in Visual Studio
3. Restore NuGet packages
4. Build the solution
5. Run the application using IIS Express

## Usage

1. Launch the application in your browser
2. The Scheduler displays a calendar with sample appointments
3. **To copy**: Select an appointment and press Ctrl+C
4. **To cut**: Select an appointment and press Ctrl+X
5. Click a different date/time slot
6. **To paste**: Press Ctrl+V to place the appointment at the new location

## Configuration

The Scheduler is configured with the following settings:
- Height: 550px
- Selected Date: August 15, 2023
- Quick Info: Disabled
